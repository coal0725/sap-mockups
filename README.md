# SAP 개선안 시안

삼성표준인증원 ISO 인증심사 신청 플랫폼의 화면 개선안입니다.
검수 산출물의 **확정안**이며, 화면 구성 · 문구 · 배치 · 필수 여부 · 조건부 표시의 기준입니다.

스타일은 참고용입니다. 통째로 복사하지 말고 프로젝트 구조에 맞게 옮겨 주십시오.
조건부 표시 규칙은 `data-when="필드:값"`, 필수 항목은 `data-req` · `data-reqgroup` 속성에 있습니다.

## 신청 플로우 — 진행 순서

| 단계 | 화면 | 기능 |
|---|---|---|
| — | [웰컴 · 인증심사 신청](SC-001-welcome-proposal.html) | 진입점 |
| 1 | [신청서 작성](SC-002-application-form-proposal.html) | FN-AP-001 |
| 2 | [설문 작성](SC-003-survey-proposal.html) | FN-AP-002 |
| 3 | [서류 첨부](SC-005-attach-proposal.html) | FN-AP-012 · 013 · 014 |
| 4 | [계약서 서명](SC-004-contract-proposal.html) | FN-AP-003 · 007 |
| 5 | 최종 확인 · 제출 | FN-AP-011 · 015 |

**화면 번호는 기능정의서의 식별자이며 진행 순서와 다릅니다.**
서류 첨부(SC-005)가 계약서 서명(SC-004)보다 앞입니다.
계약서에 들어가는 심사 범위와 비용 근거가 첨부서류로 확정되기 때문입니다.
