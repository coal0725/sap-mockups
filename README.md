# SAP 개선안 시안

삼성표준인증원 SAP 인증심사 플랫폼의 **화면 개선안 시안**입니다.

> 삼성표준인증원 장은수 · 2026-09-28
> 문의 ssr@ssr1.co.kr

---

## 이 시안의 성격

**확정안입니다.** 참고안이 아닙니다.

시안은 아래 항목의 기준입니다.

- 화면 구성 · 문구 · 배치
- 필수 여부 — `data-req` · `data-reqgroup` 속성
- 조건부 표시 규칙 — `data-when="필드:값"` 속성
- 네비게이션 약어 — `data-nav` 속성
- 상태 분기 — `data-state` 속성

**스타일은 참고용입니다.** 통째로 복사하지 마시고 프로젝트 구조에 맞게 옮겨 주십시오.

### data-state 에 관하여

`SC-007` · `SC-008` 의 상태 표시는 **표시 문자열이 아니라 `data-state` 속성으로 분기**하도록 만들었습니다.

```html
<span class="cs-state" data-state="valid">유효</span>
<span class="cs-state" data-state="suspended">정지</span>
```

문구가 바뀌어도 화면이 깨지지 않습니다. 표시 문자열로 조건을 걸지 마시기 바랍니다.

## 화면 번호 규칙

**문자 접미사가 붙은 화면은 기능정의서에 없는 신설 화면입니다.**

```
SC-006B   제출 완료 · 접수번호 안내
SC-010B   인증변경 접수 완료
```

두 화면 모두 기능정의서에 이동 가능 화면으로만 적혀 있고 화면 ID 가 부여되어 있지 않아 신설하였습니다.

### SC-011 인증변경 상세 신청

기능정의서 화면흐름에 `/change/form/detail` 로 적혀 있으나 **삭제 대상으로 판단했습니다.**

변경신청서 서식이 신청서와 확인서가 한 장으로 묶인 양식이므로 화면을 두 장으로 나눌 이유가 없습니다. 해당 경로는 현재 404 입니다.

## 시안 여는 방법 — SC-007 · SC-008

**두 화면은 독립 페이지가 아니라 웰컴 화면 위에 열리는 오버레이입니다.**

링크를 누르면 웰컴 화면이 먼저 보입니다. 화면 **하단의 검은 막대**에서 상태를 골라 주십시오.

```
SC-007   조회 입력 · 계약 검토 중 · 반려 · 계약 확정 · 심사 진행 중 ·
         시정조치 필요 · 인증 결정 완료(2차) · 인증 거부(2차) ·
         조회 실패 · 접수번호 찾기 · 발송 완료

SC-008   검색 입력 · 조회 결과 · 결과 없음
```

그 막대는 **시안 확인용이며 구현 대상이 아닙니다.**

`SC-010` 과 `SC-010B` 는 오버레이가 아닌 **독립 페이지**이므로 링크를 누르면 바로 열립니다.
`SC-010` 은 인증번호 뒤 5자리에 `00422` 를 넣고 「인증 확인」을 누르시면 조회 결과가 표시됩니다. `29999` 를 넣으면 정지 · 취소 안내가 표시됩니다.

### 왜 오버레이인가

두 화면 모두 웰컴 화면에서 직접 진입합니다. 별도 페이지로 이동하면 기업이 신청 흐름에서 이탈한 것으로 느끼고, 닫은 뒤 돌아갈 곳이 명확하지 않습니다.

닫는 경로는 세 가지를 모두 두었습니다 — `X` 버튼 · 배경 클릭 · `ESC` 키.

### SC-009 인증현황 상세

현재 구현에 `/cert/detail` 이 있으나 **시안을 만들지 않았습니다.**

대외 공개 범위(SSR-P-901 3.2.2)가 6개 항목뿐이어서 목록에 모두 담기고, 상세 화면에 추가로 보일 정보가 없습니다. 상세 화면 삭제 여부는 검수 항목 `SC009-01` 에서 판단을 요청드렸습니다.

## 화면 순서에 관하여

**서류 첨부(SC-005)가 계약서 서명(SC-004)보다 앞입니다.**

계약서에 들어가는 심사 범위와 비용 근거가 첨부서류로 확정되기 때문입니다. 기능정의서의 화면 번호는 반대로 되어 있으며 문서 정정 대상입니다. 화면 ID 는 기능정의서를 따르되 진행 순서는 위 표를 따릅니다.

## SC-006B 에 관하여

현재 구현에 없는 화면입니다. 기능정의서 「5. 화면 흐름」에 SC-006 의 이동 가능 화면으로 「접수번호 안내」가 적혀 있으나 화면 ID 가 부여되어 있지 않아 신설하였습니다.

최종 제출 후 웰컴 화면으로 돌아가면 접수번호를 전달할 수 없고 제출 여부도 알 수 없어, 기업이 같은 신청을 다시 하게 됩니다.

## 시안에 넣지 않은 것

의도적으로 비워 둔 항목입니다. 시안에 없다는 이유로 넣지 말아 주십시오.

| 항목 | 이유 |
|---|---|
| 인증번호 생성 | 채번 주체는 SAP 이 아닙니다. 인증서 발행 시 인증원이 부여한 번호를 받아 표시만 합니다 |
| 인증상태 자동 전환 | 만료일이 지나도 시스템이 취소로 바꾸지 않습니다. 상태 변경은 인증원의 결정 행위입니다 |
| 인증서 내려받기 | 본원 홈페이지에서 로그인한 기업이 자사 인증서를 받습니다 |
| 조회 시도 횟수 제한 | 비회원 조회이므로 잠글 대상이 없고, 오타로 막히면 기업이 조회를 못 합니다. 실패는 감사 로그에만 남깁니다 |
| 대표자 · 사업자등록번호 공개 | 대외 공개 범위(SSR-P-901 3.2.2)에 없습니다 |
| 인증변경 임시저장 | 변경신청서 서식이 한 장짜리 양식이라 이어쓰기가 필요하지 않습니다 |
| 인증변경 접수번호 | 번호를 발급하지 않고 인증원이 담당자에게 직접 연락합니다 |
